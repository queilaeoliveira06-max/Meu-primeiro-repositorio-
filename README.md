# Meu Projeto

Página web simples de boas-vindas, criada como primeiro projeto versionado com **Git** e **GitHub** na Fatec Santana de Parnaíba.

## Sobre

O projeto é composto por uma única página HTML (`index.html`) que exibe a mensagem:

> **Olá, Fatec Santana de Parnaíba!**
> Meu primeiro projeto versionado com Git e GitHub.

O objetivo é praticar o fluxo básico de versionamento: criar commits, trabalhar com branches e abrir pull requests.

## Estrutura

```
meu-projeto/
├── index.html   # Página inicial
└── README.md    # Descrição do projeto
```

## Como executar

Não é preciso instalar nada. Basta abrir o arquivo `index.html` em qualquer navegador:

1. Clone o repositório:
  ```bash
  git clone <url-do-repositorio>
  ```
2. Abra o arquivo `index.html` no navegador (duplo clique ou arraste para a janela).

## Tecnologias

- HTML5
- Git e GitHub
